# Changelog

All notable changes to the Video Input filter are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-26
- Initial release. Sends attached videos to video-capable models as `video_url`
  parts, with a size limit valve and an owner check on every file.
